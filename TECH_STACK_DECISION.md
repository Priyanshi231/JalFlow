# JalFlow – Tech Stack Decision

**Developer:** Priyanshi Jain  
**Project:** JalFlow – Water Tanker Management System

## What I am building

JalFlow is a web-based management system for local water tanker suppliers. It helps manage customer bookings, driver assignments, delivery status, payments and basic business reports from one dashboard.

## Tech Stack

- **Frontend:** React.js with Vite
- **Styling:** CSS
- **Backend:** Node.js with Express.js
- **Database:** MongoDB with Mongoose
- **API:** REST API
- **Client communication:** Axios

## Why this stack

I selected the MERN stack because the project is a data-driven web application with forms, records, status updates and dashboard views. React makes the interface reusable and easier to organise into components. Express and Node.js provide a straightforward REST API layer, while MongoDB is suitable for storing customers, bookings, drivers and payments with Mongoose references between related records.

## Core Features in Scope

1. Dashboard
2. Customer details through booking creation
3. Booking creation and listing
4. Driver management
5. Driver assignment
6. Delivery status updates
7. Payment records
8. Basic reports and analytics

## Out of Scope for This Version

- Live GPS tracking
- Online payment gateway
- WhatsApp/SMS automation
- Customer mobile application
- Advanced AI forecasting
